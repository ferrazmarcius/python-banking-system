# 🏦 Sistema Bancário em Python

Este repositório centraliza o desenvolvimento de um simulador de sistema bancário em Python. O projeto demonstra a evolução prática de uma arquitetura funcional simples para uma estrutura robusta e modular baseada em Programação Orientada a Objetos (POO).

## 📁 Estrutura do Monorepo

| Diretório | Descrição |
| :--- | :--- |
| **`v1_fundamentos_funcionais/`** | Implementação inicial focada nas operações bancárias básicas (depósito, levantamento e extrato) utilizando dicionários, funções e estruturas de controlo fundamentais. |
| **`v2_orientacao_a_objetos/`** | Refatoração completa aplicando POO. Introduz classes distintas para Clientes, Contas, Transações e Histórico, garantindo o encapsulamento e seguindo a modelação UML. |
| **`docs/`** | Guarda os diagramas UML e documentação visual de apoio à arquitetura do projeto. |

## 🛠️ Tecnologias e Conceitos

* **Linguagem:** Python 3
* **Paradigmas:** Programação Estruturada e Programação Orientada a Objetos (POO)
* **Arquitetura de Software:** Encapsulamento, Herança, Polimorfismo e Modelação UML
